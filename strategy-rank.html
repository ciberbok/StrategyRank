USER GUIDE // STRATEGY RANKER — DATABANK EDITION
📁 What is this?

Load a CSV where each row is an already-evaluated strategy with pre-computed KPIs (e.g. a G5 Databank export). Choose which numeric columns to rank on, assign weights, and score every strategy 0–100 using percentile normalization.

📐 Percentile Normalization
P(i,k) = rank(value_i) / (n − 1) [midpoint for ties] If "Less is Better": P = 1 − P Score = Σ(P(i,k) × Weight_k) × 100 → range: 0 – 100
↕ KPI Direction — ▲ MORE vs ▼ LESS

Controls how the percentile rank maps to score:

▲ MORE IS BETTER → high value → high percentile → high score e.g. Net Profit, Sharpe, Win Rate, Profit Factor, Ret/DD Ratio ▼ LESS IS BETTER → low value → high percentile → high score e.g. Max Drawdown, Max Consec. Losses, MAE
⚠ "Max Consec. Losses" and drawdown columns are auto-flagged as LESS IS BETTER.
💾 Session Persistence

The last loaded file (data + config) is automatically saved in the browser. When you reopen the app the entire state is restored — data, selected KPIs, weights, directions, annotations — so you can continue exactly where you left off without reloading the CSV.

🗂 KPI Configuration Profiles

The KPI CONFIGURATIONS panel lets you save named profiles of your current KPI selection + weights. Two storage options:

SAVE TO BROWSER → stored in this browser, survives page reloads, quick to apply EXPORT .json → downloads a file you can share, use on other machines, or archive LOAD FROM FILE → import a .json profile back into the app

Profiles are applied by clicking ▶ APPLY. If the loaded CSV is missing some KPIs from the profile, those are silently skipped and you'll see a warning.

💾 Export Results

EXPORT CSV downloads the ranked table with all original columns plus __RANK, __SCORE, per-KPI percentiles (__PCT_…), and any annotations you typed.
